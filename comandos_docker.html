Docker Viewer — Comandos Docker

Referencia rápida · Javier Navarro (Shira) · 2026

Desarrollo

Primera vez / tras cambios
Construye la imagen y levanta el entorno de desarrollo
docker compose -f docker-compose.dev.yml up --build
Arranque normal
Levanta sin reconstruir (para uso cotidiano, hot-reload activo)
docker compose -f docker-compose.dev.yml up

Producción

Primera vez / tras cambios en código o Dockerfile
Construye y levanta en modo producción
docker compose up --build
Arranque normal
Levanta sin reconstruir
docker compose up

Parar

Parar y borrar volúmenes (rebuild limpio)
Detiene todos los servicios y elimina los volúmenes
docker compose down -v
-f docker-compose.dev.yml le dice a Docker qué archivo compose usar.
Sin ese flag usa docker-compose.yml (producción) por defecto.
